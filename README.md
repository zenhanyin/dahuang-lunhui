# 大荒轮回录

《大荒轮回录》是一款纯前端文字 RPG / 轮回模拟器。玩家在大荒醒来，带着模糊记忆经历多世轮回，通过出身、门派、游侠路线、人物羁绊与道德/因果选择，逐步接近太古铜门背后的真相。

## 当前定位

- 类型：文字 RPG、轮回模拟器、轻视觉小说表现层
- 题材：山海经神话气质的大荒世界延展
- 核心体验：多世记忆、随机出身、数值成长、门派分支、人物线、结局判词
- 运行方式：静态网页 + Sites Worker

## 核心玩法

- 开局随机醒来地点与出生底子。
- 玩家可选择门派路线，也可保持游侠身份。
- 每一世约按三十年叙事节奏推进。
- 道德、因果、灵力、记忆等状态会影响选择与结局。
- 部分记忆、悟性和线索会跨世保留，让玩家逐步接近真相。

## 主要路线

- 天机营：北墙、军册、七夜与武观相关线。
- 冰心堂：清时、海寂、药灯与药账相关线。
- 弈剑听雨阁：青阳、雨亭、剑与铜门侧路相关线。
- 云麓仙居：莫非云、星图、白羽与东海潮声相关线。
- 荒火营地：太子长琴、圣火、乐风与九黎余焰相关线。
- 魍魉：旧令、影子与信任边界相关线。
- 玄晖线：幽都、雪线、金灯与东皇旧名相关线。
- 游侠线：渡口、旧账、活人名册与不入门派的见证路线。

## 技术结构

- `index.html` / `text-adventure.html`：游戏主界面与运行逻辑。
- `story-config.xlsx`：剧情配置表，便于人工维护文本。
- `story-config.js`：由配置表同步出的运行时剧情数据。
- `assets/`：场景图、头像、图标等视觉资源。
- `build-site.js`：生成 Sites Worker 入口，内嵌剧情配置、资源与接口。
- `drizzle/`：统计表结构。
- `tools/`：剧情同步、检查和风险测试脚本。

## 线上发布规则

- `main`：开发主线，保存最新源码。
- `gh-pages`：GitHub Pages 发布分支，只在明确发布 GitHub 时更新。
- Sites 内部仓库：只用于 `chatgpt.site` 发布，不和 GitHub 混用。

## 本地维护

剧情文本优先维护 `story-config.xlsx`，再通过同步脚本生成 `story-config.js`。修改完成后应运行文本质量、剧情流、头像映射和风险检查，再进入发布流程。
